# SQL Injection Prevention Platform

A comprehensive learning platform for SQL Injection prevention, detection, and analysis.

## Features

- **Home Page**: Overview of platform features with integrated dashboard and query analyzer
- **Query Analysis**: Analyze SQL queries for potential injection vulnerabilities
- **Dashboard**: Visualize SQL injection statistics and attack trends
- **Live Monitoring**: Real-time monitoring of database queries
- **Attack Logs**: Browse and analyze detected SQL injection attacks
- **Honeypot**: Deploy honeypot databases to capture SQL injection techniques
- **Chatbot**: Get assistance and learn about SQL injection prevention
- **API Docs**: Documentation for integrating with your applications
- **Admin Settings**: Configure the platform settings

## Getting Started

### Prerequisites

- Node.js (v14+ recommended)
- npm or yarn


## Usage

### Analyzing Queries

1. Navigate to the Query Analysis page
2. Enter your SQL query in the input field
3. Click "Analyze Query" to check for vulnerabilities
4. View the results and follow the recommendations

### Dashboard Analysis

The dashboard provides comprehensive statistics on:
- SQL injection attempt types
- Detection and prevention rates
- Real-time query monitoring
- Attack trend visualization
